# MLOps Hands-on 1 & 2

Paket kerja untuk menjalankan studi kasus MLflow dari slide MLOps ITERA dan mengikuti susunan laporan contoh.

- Hands-on 1: logging dasar RandomForest pada Breast Cancer Wisconsin.
- Hands-on 2: pipeline end-to-end: data/hash, baseline, model selection, tuning, pemilihan kandidat, evaluasi test, registry, serving, reproduction.

Gunakan PowerShell di Windows dan jalankan perintah dari folder masing-masing hands-on. Tidak perlu dataset eksternal; dataset tersedia dari scikit-learn.
